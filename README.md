# HTML Works Hub

単体HTMLで動く**全71作品**のハブサイトです。項目別（カテゴリ別）に整理し、全作品にスマホ対応（viewport・タップ最適化シム）を注入済み。各作品は全画面ビューワー（`viewer.html`）で開き、スマホでは「全画面（横）」ボタンで横向き全画面表示になります。
